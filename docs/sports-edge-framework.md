# 体育预测市场 Edge 框架 v1.0（2026-10-11）

目标：在 Gate 预测市场（底层 Polymarket 流动性）上，用"模型概率 vs 市场概率"的价差找 +EV 机会。
边界：全程纸面验证，$0 不下场；不做自动实盘跟单。

## 1. 总体架构（五层）

数据层 -> 模型层 -> 信号层 -> 资金管理层 -> 纸面验证层

每一层独立可替换。任何一层掉链子，整条链路就是负期望。

## 2. 数据层：三个赔率源

- Gate 预测市场：执行端的市场价（我们要吃的那一端）。待调研回填：费用、盘口深度、有无 API。
- Polymarket 公开 API：交叉验证价。Gate 底层就是它，理论同价，出现偏离即套利信号。已验证可用。
- Pinnacle 赔率：基准真值。全世界最 sharp 的盘，用它当"真实概率"的代理。需解决获取方式。

核心逻辑：Pinnacle 隐含概率 ≈ 真实概率；Gate/Polymarket 偏离它的部分 = 潜在 edge。

## 3. 模型层：从简到繁

- P0（先跑起来）：Elo 评分。只用历史赛果，每场比赛更新两队 Elo，换算成胜/平/负概率。优点是零数据成本、半天能写完。
- P1：xG 期望进球。需要射门数据（免费源待找），比 Elo 多一层信息。
- P2：信息流。伤病、首发名单、临场消息——AI 24 小时盯新闻/社媒，这是机器对人的真实优势，也是模型最难量化的部分，单独做加成项。
- 原则：一次只加一个变量，加完用回测验证有没有提升，没有就砍掉。

## 4. 信号层：只吃定价错误

- edge = 模型概率 - 市场隐含概率（含手续费调整后）。
- 只做 edge > 阈值（比如 5%）的单子，低于阈值一律放弃——大部分时间应该是空仓。
- 用 Closing Line Value（CLV）衡量质量：下单时的赔率 vs 封盘时的赔率，长期 CLV 为正 = 真有 edge，这是职业玩家的标准尺子，比短期盈亏可靠。
- 不碰：自己模型没覆盖的联赛、流动性太差的盘（滑点吃掉 edge）、情绪盘（纯新闻事件）。

## 5. 资金管理层：保命

- Kelly 公式定注额，实际用 1/4 Kelly（职业玩家的保守档）。
- 单注上限：bankroll 的 2%，再有信心也不加。
- 回撤熔断：bankroll 跌 20% 停手复盘，不是加倍追。
- 这是整个框架里最重要的一层，比模型本身重要。

## 6. 纸面验证层：两步走

- 第一步回测：拿历史赔率跑模型，看如果过去一年按信号下单是什么收益、最大回撤多少。回测为负直接砍，不进入第二步。
- 第二步前瞻纸面：每天记录"模型会下什么单、什么赔率"，赛后结算，跑 4-8 周。前瞻为正，才算"好像有利润能赚"得到初步验证。

## 7. 联赛选择标准

- 流动性够（Gate/Polymarket 上有稳定盘口）
- 历史数据免费可得
- 赛季正在进行或即将开始
- 候选：英超（数据最多、最 sharp，难但标准）、CS2 电竞（更软、数据少，可能是洼地）

## 8. 诚实的风险声明

- 即使 +EV，方差极其残酷，连黑十几单正常，没有资金管理必死。
- 模型风险：Elo 在杯赛、换帅、保级战等场景系统性失效。
- 市场会变 sharp：2026 世界杯把大量资金和聪明钱吸进来，edge 可能比平时薄。
- 法律/合规：大陆在线体育博彩不合法，平台访问是灰色地带，自行掂量。

## 10. 方法论调研回填（2026-10-11，子代理核验）

### 核心发现：路线可能要反过来

最有价值的一个实战对照：同一个作者，先做 ML 预测模型——CLV 轻微为负（无 edge）；改做 value betting scanner（不预测、只扫描错定价的赔率）——224 单纸面，平均 CLV +4.00%，71.7% 的单 beat 收盘，ROI +10.8%。作者结论："预测不产生 edge，赔率 shopping 才产生。"

这意味着 P1 不一定从 Elo 建模开始。**scanner-first 路线**（跨市场扫价差，不预测）比 model-first 更简单、更 robust：
- 数据层已经齐了：Gate/Polymarket 市场价 vs Pinnacle 基准价，价差即信号
- 不需要历史数据、不需要模型校准，工程量小一个量级
- 验证标准天然就是 CLV

### 各方法实证摘要

- Elo：世界杯 115 场淘汰赛回测，胜方准确率 73.9% vs FIFA 排名 68.7%，是好的地基；但论文明确警告"光靠排名系统跑不赢庄家"——Elo 是起点不是 edge。
- xG：提升真实但微小（1X2 命中率 50.7%→50.8%，Brier 0.1994→0.1990）；Wilkens 11 个德甲赛季回测 ROI 10-15%，但利润主要来自押主胜、各赛季波动大，单点结果别当真。
- CLV：公式 =（你的赔率/收盘赔率 − 1）。200-500 单就能判断有没有 edge（ROI 要 2000-5000 单）；平均 CLV 百分比约等于长期 ROI；持续 55%+ beat 收盘 = 真本事。
- Polymarket 低效点：UCLA 2026 论文——主流盘微观结构极有效，错定价中位数 3.6 秒消失，76.9% 的套利机会被深度锁死。**主流大盘别指望捡漏**。真机会在跨市场滞后（Polymarket 曾落后 Betfair 数小时）和小联赛（缺硬回测，逻辑自洽）。
- 电竞：盘软（patch 一夜改 meta、历史数据少）但 Oddin.gg 高管直言"最难盈利的市场之一"——软≠好赚，波动反噬大。缺免费聚合数据源是实际门槛。
- Kelly：没人用全 Kelly；职业用 1/4 或 1/2；校准比公式重要（高估 5% 胜率，全 Kelly 注额变 5 倍）。

### 框架调整

- P1 改为 scanner-first：Gate/Polymarket vs Pinnacle 跨市场扫价差，纸面记录 200 单，看平均 CLV。
- Elo 建模降为 P2（scanner 跑通之后再叠加）。
- 预期：可复制的 edge 大概率在 2-5% CLV 量级，这已是职业水平；别信 10%+ ROI 的故事。

## 11. Gate 版落地实施（2026-10-11）

基于五层理论，针对 Gate 预测板块的三处不同（费用/无 API/准入）做的具体调整。

### 三处不同

1. 费用：Gate 平台费 0.8%/边（maker/taker 双收），限价单免 Polymarket 协议费。所以**只挂限价单**，往返成本 1.6%。市价单 3.3%/边，碰都别碰。
2. 无 API：预测板块大概率只有 App/网页端，程序化执行走不通。scanner 负责发现（用 Polymarket 公开 API，同一订单簿价格一致），执行靠人手。
3. 准入：大陆官方受限 + 全员强制 KYC，合规自己解决。

### 五层落地

**数据层**：Polymarket gamma API（事件）+ CLOB book（实时盘口深度）做市场价；the-odds-api 拿 Pinnacle 基准价；Gate App 内聪明钱标签/异动提醒做辅助交叉验证（不跟单）。

**模型层**：scanner-first。跨市场价差即信号，不预测。Elo 降级 P2。

**信号层（Gate 版规则）**：
- 净 edge = |poly 价 - pinnacle 价| - 1.6%（往返成本），净 edge > 4% 才动手。scanner 里 `--venue gate` 已内置这个逻辑。
- 只挂限价单：在目标价挂，不追市价；CLOB book 看深度，要吃的量滑过阈值就放弃。
- 不碰：流动性差的盘、已出结果的、情绪盘。

**资金管理层**：1/4 Kelly，单注上限 bankroll 2%，回撤 20% 熔断。Gate 侧 USDT 资金单独记账，不跟现货账户混。

**纸面验证层**：
- scanner 纸面记录到 scanner_log.csv（已跑通）。
- 每天固定时间跑一次 `--venue gate`，人工复核 top 信号：App 内确认价格一致、book 深度够。
- 记录"假设挂单价"和 Pinnacle 价，赛后算 CLV。200 单、平均 CLV +2% 以上、beat 率 55%+ 才算验证通过。

### 每日 SOP（15 分钟）

1. 跑 `python3 sports_odds_scanner.py --venue gate --odds-key KEY`，看 scanner_log 新增信号。
2. 对每条信号：Gate App 内核对价格是否一致；看 CLOB book 深度够不够吃。
3. 纸面记录：挂单价、数量、Pinnacle 基准价、时间戳。
4. 比赛结束后记录收盘价，算 CLV。
5. 每周复盘：平均 CLV、beat 率、信号数量。

### 还差的东西

- the-odds-api 免费 key（用户注册，500 req/月）。
- Gate 侧准入（KYC/网络，用户自己）。
