# 加密预测方法论框架 v1 (2026-10-11)

## 定位
只做 **Polymarket 加密价格盘** (BTC/ETH/SOL)，分两层：
- **Tier 1 短期** (≤7天结算)：每日价格盘，快周转
- **Tier 2 长期** (>7天结算)：季度/年度价格目标

不做体育（已验证走不通），不做跟单（已证伪）。

## 五层判断法（稳定性）

### ① 期权隐含分布（核心基准，权重最高）
- **数据源**：Deribit BTC/ETH 期权链（`get_book_summary_by_currency`）
- **方法**：取到期日最接近目标结算时间的平均 IV → 对数正态分布 → 理论概率
  - P(above X) = 1 − N((ln(X/S) + ½σ²T) / (σ√T))
- **为什么专业**：期权市场是全球最聪明的钱对波动率的定价，前瞻性强于任何历史统计
- **局限**：超短期（<24h）IV 失真；SOL 无 Deribit 期权链，用 realized vol；
  **2026-10-23 铁律**：波动率锚拿不到就直接报"无信号"，不再降级硬报 —
  BTC/ETH 的 Deribit IV 失败时不再降级 realized，realized 数据不足时也不再造 60% 假数

### ② 聪明钱流向（验证，非跟单）
- **数据源**：Gate Smart Money/Whale 标签、Polymarket 链上大额持仓
- **用法**：反向指标——模型说买 Yes，若大户重仓买 No，则跳过（模型可能漏了信息）
- **注意**：机械跟单已证伪（回测负期望），只做刹车，不做油门

### ③ 订单簿深度（价格真实性）
- **数据源**：Gate MCP `get_market_orderbook`
- **规则**：买卖价差 > 10% 直接跳过；价差 5-10% 降档；<5% 才按报价算 edge
- **原因**：报价虚的话，算出来的 edge 不存在

### ④ 期限结构一致性
- **方法**：同一标的相邻到期日的隐含波动率应平滑过渡
- **规则**：若某一天的 edge 显著偏离相邻两天，优先怀疑数据而非机会

### ⑤ 历史校准（唯一真理标准）
- **方法**：`crypto_signals_log.csv` 记录每个信号的模型概率 → 结算后填 outcome
- **标准**：50 个信号后，模型说 60% 的组实际发生率应在 50-70% 内，否则修模型
- **二次分析**：定期跑校准报告，看哪些币种/哪类盘口系统性偏离

## 稳定性评分 (0-100)
| 维度 | 满分 | 规则 |
|---|---|---|
| edge 分 | 40 | 净 edge 5%=0分，50%+=40分，线性 |
| 概率分 | 25 | 模型概率 40-70% 最优；<10% 或 >90% 扣分（避开彩票和送分题） |
| 流动性分 | 15 | 价格越接近 50¢ 通常深度越好 |
| 稳健分 | 10 | 波动率 ±30% 不翻转信号方向 |
| 时效分 | 10 | 24h内结算=10分，7天=0分，线性 |

## $50 仓位区间（半凯利 + 2% 硬顶）
| 评分 | 金额 | 仓位比 |
|---|---|---|
| 80+ | $1.00 | 2% |
| 60–80 | $0.75 | 1.5% |
| 40–60 | $0.50 | 1% |
| <40 | 跳过 | — |

**铁律**：
- 每天最多 3 注
- 同一标的、同一到期只选一个（高度相关，不算独立注）
- 模型概率 <20% 的彩票票直接跳过，不管 edge 多大

## 数据源清单
| 数据 | 来源 | 用途 |
|---|---|---|
| Polymarket 价格 | gamma-api 原生（按 endDate 过滤） | 信号源 |
| BTC/ETH 现价 | Gate 现货 API | 模型输入 S |
| 隐含波动率 | Deribit 期权链 | 模型输入 σ |
| 备用波动率 | Gate K线 realized vol | 仅 SOL 使用；数据不足时直接报无信号，不造假数 |
| 聪明钱 | Gate App 标签 / 链上 | 反向验证 |
| 订单簿 | Gate MCP get_market_orderbook | 价格真实性 |
